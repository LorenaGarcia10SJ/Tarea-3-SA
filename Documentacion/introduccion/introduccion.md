## INTRODUCCIÓN

Este proyecto consiste en el desarrollo de una API RESTful para la gestión de una Base de Datos de Gestión de Configuraciones (CMDB). La API permite administrar Elementos de Configuración (CIs), que representan activos tecnológicos como servidores, aplicaciones, bases de datos, entre otros.

La API está desarrollada usando Node.js con el framework Express, y utiliza PostgreSQL como sistema gestor de base de datos. Se ha implementado un modelo relacional completo que incluye tablas para los CIs, sus relaciones y auditorías.

El objetivo es proporcionar una solución escalable, modular y fácil de usar para gestionar la configuración y dependencias dentro de una infraestructura tecnológica.
